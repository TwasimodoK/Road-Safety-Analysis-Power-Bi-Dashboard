# Road Safety Analysis Dashboard – Power BI

This project analyzes road accident data from the UK to uncover key patterns and trends using Power BI. It was created as part of a task for an internship selection at the Indian Institute of Science (IISc), Bengaluru.

## 📊 Dashboard Features
- Accident severity and monthly trends
- Spatial and environmental conditions
- Vehicle and road-type analysis
- KPIs using DAX (e.g., fatality rate, urban share, high-speed accidents)
- Interactive filters and navigation buttons

## 🧹 Data Preparation
- Cleaned and transformed raw data (date hierarchy, label correction, null handling)
- Created a calendar table for time-based analysis
- Designed custom DAX measures for deep insights


## 🛠 Tools Used
- Power BI  
- DAX  
- Data Modeling  
- Google Sheets (data source)
